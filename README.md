# Python Quiz System

A simple, console-based Quiz application built as part of my programming journey. This project demonstrates core Python concepts learned during the **Programming Fundamentals** course.

## 🚀 Features
- **Object-Oriented Programming:** Uses classes to manage question data.
- **File I/O:** Loads questions from external text files and saves player scores.
- **Dynamic Leaderboard:** Displays the top players sorted by their score.
- **Data Parsing:** Handles string manipulation and list processing.

## 🛠️ How to Run
1. Ensure you have Python 3.x installed.
2. Clone this repository.
3. Run the application:
   ```bash
   python main.py
